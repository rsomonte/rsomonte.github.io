Rollcage Linux Guide

Source Repository: rsomonte/rollcage_linux_guide

This guide walks through setting up Rollcage Redux (the modern source-patched version of the 1999 combat racing game) on Linux (Fedora/Ubuntu/Arch) using Wine and Lutris, as well as getting Xbox and generic controllers working smoothly.

1. System Dependencies & Controller Permissions

Install Required System Packages

Rollcage Redux requires resolution switching support (xrandr) and Vulkan tools:

  • Fedora:
    sudo dnf install -y xrandr vulkan-tools xdotool
  • Ubuntu / Debian:
    sudo apt update && sudo apt install -y x11-xserver-utils vulkan-tools xdotool
  • Arch Linux:
    sudo pacman -S xorg-xrandr vulkan-tools xdotool

Grant Controller Access (udev & Groups)

To allow Wine and SDL to read raw Xbox/gamepad event inputs:

  1. Add your user to the input group:
    sudo usermod -aG input $USER
  2. Create a permanent udev rule for gamepads (/etc/udev/rules.d/99-gamepad.rules):
    KERNEL=="event*", SUBSYSTEM=="input", MODE="0666", TAG+="uaccess"
KERNEL=="js*", SUBSYSTEM=="input", MODE="0666", TAG+="uaccess"
KERNEL=="hidraw*", MODE="0666", TAG+="uaccess"
  3. Reload udev rules:
    sudo udevadm control --reload-rules && sudo udevadm trigger

2. Fixing the Crash After Intro Logos (vcrun2013)

Root Cause

When transitioning from the video logos (Psygnosis.bik & Atd.bik) into the main 3D engine, Rollcage Redux uses Visual C++ 2013 Concurrency runtime functions (msvcr120.dll). Wine's built-in stub causes the game to abort immediately after the intro logos.

Fix via Winetricks

Install native 32-bit vcrun2013 inside your game's Wine prefix:

WINEPREFIX="$HOME/Games/rollcage" winetricks -q vcrun2013

3. Game Files & Working Directory Setup

  1. Place your extracted Rollcage Redux game folder at $HOME/Games/RollcageRedux.
  2. Ensure the main executable is located under the Direct3D folder: $HOME/Games/RollcageRedux/Direct3D/Rollcage Redux.exe

Critical Note: The Working Directory must be set to $HOME/Games/RollcageRedux/Direct3D so the executable can locate binkw32.dll and asset indexes.

4. Lutris Game Configuration

Create or update your Lutris configuration (~/.config/lutris/games/rollcage-setup-1785908900.yml):

game:
  exe: /home/$USER/Games/RollcageRedux/Direct3D/Rollcage Redux.exe
  working_dir: /home/$USER/Games/RollcageRedux/Direct3D
  prefix: /home/$USER/Games/rollcage
game_slug: rollcage
name: Rollcage Redux
slug: rollcage-setup
system:
  env:
    SDL_JOYSTICK_HIDAPI: '1'
wine:
  runner: wine-ge-8-26-x86_64

Desktop Menu Shortcut (~/.local/share/applications/rollcage-redux.desktop)

[Desktop Entry]
Name=Rollcage Redux
Comment=Play Rollcage Redux on Linux
Exec=env WINEPREFIX="/home/$USER/Games/rollcage" DISPLAY=":0" SDL_JOYSTICK_HIDAPI=1 /home/$USER/.local/share/lutris/runners/wine/wine-ge-8-26-x86_64/bin/wine "/home/$USER/Games/RollcageRedux/Direct3D/Rollcage Redux.exe"
Path=/home/$USER/Games/RollcageRedux/Direct3D
Icon=/home/$USER/.local/share/lutris/banners/rollcage.jpg
Terminal=false
Type=Application
Categories=Game;ArcadeGame;

5. In-Game Controller Setup

  1. Launch Rollcage Redux (via Lutris or App Launcher).
  2. On the initial setup dialog, click Play.
  3. In the main menu, navigate to Options $\rightarrow$ Controls $\rightarrow$ P1 Controller.
  4. Change the selected device to Xbox One Controller (or your connected gamepad).
  5. Redefine Controls:
    • Highlight Redefine Controls (or press Enter on it).
    • Press each corresponding button / stick direction on your gamepad to map actions (Accelerate, Brake, Steer Left/Right, Fire, Use Item).
  6. Save settings and enjoy the game!

Note: I used A for acceleration and B for braking and reversing, because using the triggers would also allow left stick front and back to work as acceleration and braking respectively
